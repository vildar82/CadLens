CAD Lens

Version 1.0.0. Explore a drawing by layer, object type, and property. Find, select, focus on, and temporarily isolate objects without changing stored DWG geometry or properties.

Get started

  1. Open a drawing in AutoCAD or Civil 3D. Click CAD Lens on the Plug-Ins ribbon tab or enter CADLENS.
  2. Press Layers or Objects in the compact bar.
  3. Choose a layer or type, then browse its objects. Use breadcrumbs or Back to return.
  4. Use Focus, Select, or Isolate on the current target. Press the active lens button to collapse the panel.

Running CADLENS again brings the existing panel forward. Drag empty header space to move it.

Commands

Command Action
CADLENS Open or activate the drawing explorer.

Explore the drawing

Layers follows Layer → Type → Object. Objects follows Type → Object across included layers. Search, inclusion filters, and sorting help narrow the list.

All objects reads direct objects in the active model or paper space. Selected objects captures the current CAD selection or prompts for one. Clicking it again captures a new selection. Press Escape during the prompt to keep the previous view.

Use Refresh after drawing edits. Within an object type, use Show property to choose the displayed value and Group by to combine observed properties. Grouping and sorting use the last captured inventory.

Drawing controls

  • Focus fits the current target in the active view.
  • Select replaces the CAD selection with the current target.
  • Isolate temporarily hides other direct objects in the active space.

Each action has an independent Auto toggle. All start off; saved choices apply when you choose a target. For selection without camera movement, enable Auto Select and leave Auto Focus off.

Returning to the root, turning Auto Isolate off, collapsing or closing the panel, or switching drawings or spaces clears temporary isolation. With Auto Isolate off, navigation clears a manual isolation. Reset clears selection, isolation, and Auto modes while keeping the camera and navigation.

Preferences

The EN/RU menu selects English, Russian, or the Windows display language. The gear menu chooses a theme, palette, and accent color. Drawing names and identifiers retain their original text.

Preferences are saved under %LOCALAPPDATA%\CadLens. Each lens keeps its own controls, filters, search text, sorting, and property choices. A new panel session starts collapsed with All objects selected.

Compatibility

The bundle targets 64-bit Windows with AutoCAD and Civil 3D 2019–2027.

Host versions Runtime baseline
2019–2020 .NET Framework 4.7
2021–2024 .NET Framework 4.8
2025–2026 .NET 8
2027 .NET 10

A compatible later .NET Framework 4.x runtime also satisfies the legacy requirements. The host selects the matching payload automatically. AutoCAD LT, macOS, and AutoCAD 2018 or earlier are outside the release scope.

Installation and removal

For an Autodesk App Store installer, close AutoCAD and Civil 3D, then run the downloaded installer. It installs the plugin automatically. To remove it, close the host and uninstall CAD Lens through Windows Settings > Apps.

For the GitHub ZIP distribution, extract CadLens.bundle.zip and copy the complete CadLens.bundle directory to %PROGRAMFILES%\Autodesk\ApplicationPlugins. Restart the host and enter CADLENS. Updating a manual installation means replacing the entire bundle directory while the host is closed. To remove a manual installation, delete that bundle directory.

Known limits

  • Nested block and external-reference contents are not traversed; an insertion remains one drawing target.
  • Objects on off or frozen layers remain hidden even when included in the list.
  • Focus can be unavailable when bounds cannot be read or the viewport is locked. Select remains available.
  • Drawing edits require Refresh. Counts include objects outside the visible camera.

Host support describes the intended version range. See the verification guide for the recorded evidence and native checks.

Privacy and support

CAD Lens works locally and does not automatically upload drawing information. Ctrl+Shift+F12 in the panel creates an optional diagnostic JSON file on your Desktop; review it before sharing it.
